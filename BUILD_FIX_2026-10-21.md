## How to rebuild

1. Extract ZIP and upload **contents** of `live_tv_remote/` into the GitHub repository root, including `.github/`.
2. Commit the updated files (overwrite the old versions).
3. From the repository, use **Actions → Android TV APK → Run workflow**.
4. If all checks pass, download artifact **Live-TV-Remote-AndroidTV-arm64** containing `app-release.apk`.

The output is a sideload/testing APK signed with the **debug key**, not ready for Play Store.
