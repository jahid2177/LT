# Live TV Remote — 21 October 2026 R8 release build fix

## Error seen in `logs_107179239559.zip`

- `flutter analyze --no-fatal-infos`: no issues
- `flutter test`: 11 passed
- `flutter build apk --release --target-platform android-arm64`: failed in `:app:minifyReleaseWithR8`
- R8 reported missing OEM-provided AndroidX WindowManager classes under `androidx.window.extensions.*` and `androidx.window.sidecar.*`.
- The earlier Gradle-version mismatch is **already fixed**; do not downgrade Gradle or AGP.

## Fix

1. Created `android/app/proguard-rules.pro` with narrowly scoped `-dontwarn` rules for **only** the optional AndroidX WindowManager extensions and sidecar packages.
2. Connected it to **release** via `proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")` in `android/app/build.gradle.kts`.
3. Added a CI static check in `tools/check_android_toolchain.py` to confirm both the rules and Gradle reference exist after `flutter create`.
4. Added a workflow step that uploads `missing_rules.txt` as an artifact if a future build fails.

This preserves R8 shrinking: it does **not** disable minification, switch to debug APK, add bogus vendor JARs, or globally ignore errors. Optional WindowManager extensions are supplied only on certain Android devices and should not be required for standard TV playback.
